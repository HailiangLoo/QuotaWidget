# 架构与证据边界

[English](ARCHITECTURE.md) · [图表含义](ALGORITHM.zh-CN.md)

项目保留 Core 与 WPF 两个生产工程。在现有工程里分清采集、事实、估算、展示，不为分层再增加框架。新增模块应当减少不确定性和维护成本，而不是只让目录更整齐。

## 数据链路

| 入口 | 持久数据 | 计算 | 显示 |
| --- | --- | --- | --- |
| 官方 CLI 额度读数 | 原子写入 latest.json → 按平台、账号、窗口保存历史 | RateEngine 有效区间 → 累计 / 近一小时均速 | 额度、累计与近 1h |
| 本机请求与工作事件 | TokenIndex 有界补读 → SQLite → 完整工作快照 | 工作起止约束 → ActiveRateEstimator → RateTrend | 趋势曲线 |
| 两类记录结合 | 原始额度与 token 数据均保留 | ChatQuotaEstimator 校准、验证、拒绝不稳定分摊 | 按 chat / 模型的估算 |
| 近期日志元数据 | ChatCacheMonitor 独立的近期状态 | 请求、结束、压缩边界 | 缓存提醒 |

账本只记录观测区间，不再计算旧的 15 分钟平滑。趋势统一经过现有估算器；原始速率仍是区间平均，累计仍取有效增量。旧额度配对算法和手动换算参数已删除，Fable 换算由 `QuotaUnits` 统一定义。

必须保持的边界：

- 采集器负责官方程序校验、额度请求、退避和结果持久化；不解析或复制用户现有的认证文件。官方 CLI 仍会管理其登录凭证，不能宣称“完全没有凭证”。
- 账本保留平台、账号、窗口、时间和缺口；不能用平滑重写观测、把缺失变成零，或把账号增量移动到某个 chat。
- 日志索引去重请求并保存数值、归属和起止元数据；补读未完成不能发布成“没有工作”。
- 趋势按有证据的活跃时间估算，已确认曲线面积加未定位增量守恒；任务边界优先，空闲与真实停采不能被平滑填满。
- chat 分摊是带验证和拒绝条件的估算，不能称为官方账单；Fable 共线只减少重复显示，不改两个原始计数器。

## 日志里有额度，不等于有单次请求账单

OpenAI 将 `account/rateLimits` 定义为用户账号的额度窗口读数。日志位置能说明哪个 chat 收到了读数，不能证明读数变化全部由它产生。[官方接口说明](https://learn.chatgpt.com/docs/app-server)

例如 A、B 并发时都先后读到账号 20→23。分别对两个 chat 求差会得到 6 点，账号实际只增加 3 点。统一排序、去重可以改善账号时间线，但无法确定两者各占多少。整数粒度、上报延迟、其他设备和账号切换仍须处理。

Claude Code 状态栏也可提供额度窗口，但更新有多种触发方式，并存在去抖、取消和到期窗口移除。状态栏回调不是保证逐请求发生的计费事件，也不能自动覆盖所有客户端和子代理。[官方状态栏说明](https://code.claude.com/docs/en/statusline)

将来若采用这些来源，应先验证账号、计量桶、窗口、时间、去重、缺失行为及与现有读数的一致性。它们可能降低采集成本和延迟，不能直接消除分摊的不确定性。当前没有新增钩子，也不修改其他应用的设置。

## 为什么保留这些边界

- **重置连续性**复用配置的采样间隔，并要求工作连续；跨重置区间仍不记账。慢采样本身不是停工，漏采、失败和真实结束仍截断。
- **latest.json** 同时承担持久交接、重启恢复和外部快照输入。现有文件状态检查很轻，不另加一条内存事件投递路径。
- **近期提醒与历史索引**的时间范围、游标恢复和完整性要求不同。可以复用语义一致的解析函数，不能让当前提醒等待整个历史补读完成。
- **每平台独立模型**保留各自账号、历史和存储。显示设置相同，不代表账号状态可以共享。
- **8 天**是实时加载与校准范围，不是磁盘保留期；旧历史支持日历和完整记录。当前 chat 列表只保留 24 小时是另外一条显示规则。
- **SQLite 覆盖信息**存事实，显示时生成当前语言文案；只读旧快照仍兼容旧字段。
- **回归拟合稳定不等于归属唯一**。高度相关的工作量、遗漏的异机消耗可能无法识别；没有证据时保留未知。
- **自包含单 EXE**有意包含运行时。无需为这些优化增加服务、运行时安装步骤、更新器、钩子或通用框架。

## 验证

运行[开发说明](../CONTRIBUTING.zh-CN.md)中的核心与 WPF 测试。重点保护总量守恒、非负有限速率、累计单调、账号隔离、确切工作边界、不使用未来样本，以及切换范围不改变同一时间点的估算。合成反例进入测试；真实历史只在本机回放，不能把日志、身份或凭证提交成公开夹具。
