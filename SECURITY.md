# Security

Report vulnerabilities privately using this repository's **Security → Report a vulnerability** feature when available. Do not post credentials, raw account responses, personal logs, or an entire data directory in a public issue. If credentials have been exposed, revoke or rotate them with the relevant provider first.

For ordinary bugs, open an issue with the app version, Windows version, reproduction steps, and a demo screenshot.

## 安全问题

请通过本仓库的 **Security → Report a vulnerability** 私下报告漏洞。不要在公开 Issue 中贴登录凭证、原始账号响应、个人日志或整个数据目录。若凭证已泄露，请先在相应服务中撤销或轮换。

普通功能问题可提交 Issue，附版本、Windows 版本、复现步骤和演示数据截图。
