# Assets

`quota-companion.png` and `quota-companion.ico` are original QuotaWidget artwork,
generated from `QuotaIcon.cs` and covered by this repository's MIT license.

Provider artwork is not bundled. `ProviderIcon.cs` reads identification icons from
the user's installed Windows packages, when available. Otherwise it draws original
letter/terminal badges. No icon is downloaded at runtime.

Provider names and logos belong to their respective owners. They identify the
services being monitored and do not imply sponsorship or endorsement.
